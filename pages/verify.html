Verify

Check the count yourself.

Every voted round's tally is proven with a zero-knowledge proof and verified on chain on Solana. Each round publishes a snapshot of its votes and a proof that the winner and the weighted totals follow from exactly those votes. The proof is then checked by the Neurocracy tally verifier program G4dJmDirX69n4aKo2fFx3eAnWXnn4NMZigrunpAd1nYw in a mainnet transaction, which anyone can look up. This page checks the proof in your browser against the published verification key, so you do not have to trust our server's answer.

Verify without trusting this site

Clone the repository and run the local script. It downloads the snapshot and the proof, rebuilds the Poseidon Merkle tree and the totals commitment from the snapshot, checks that they match the proof's public inputs, and verifies the proof against the verification key in the repository.

git clone https://github.com/neurocracyfun/neurocracy
cd neurocracy && npm install
node scripts/zk-verify.js ROUND

On chain: program G4dJmDirX69n4aKo2fFx3eAnWXnn4NMZigrunpAd1nYw, upgrade authority Gqok1QbCybZDLA96xeSBxVRSJ3hkJ2bCXq4FJyeMa3YA. Proven rounds currently hold up to 128 votes each.

What the proof does and does not cover is written up in docs/zk.md.
